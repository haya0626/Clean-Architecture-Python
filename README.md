# README

Python を用いて、Clean Architecture に基づいた設計・実装を行うプロジェクトです。

## 使用ライブラリ

| 種類                    | ライブラリ名                    |
| ----------------------- | ------------------------------- |
| パッケージ・Python 管理 | uv                              |
| Web フレームワーク      | fastapi                         |
| 開発用 ASGI サーバー    | uvicorn[standard]               |
| 環境変数                | pydantic-settings               |
| テスト                  | pytest / pytest-asyncio / httpx |
| Linter・Formatter       | ruff                            |
| 型チェック              | mypy                            |
